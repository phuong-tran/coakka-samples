# Trademarks

CoAkka, the CoAkka name, and package or image names using the `coakka` prefix
identify the CoAkka project and its official artifacts.

You may use the CoAkka name to refer truthfully to this project, compatible
integrations, and unmodified official artifacts. Do not use the CoAkka name,
logo, package names, image names, or confusingly similar marks to imply that an
unofficial fork, runtime, hosted service, or product is endorsed by or
affiliated with the CoAkka project.

Forks and derived samples should use their own project names. They may state
compatibility with CoAkka when that statement is accurate and does not create
confusion about origin or support.

## Examples

Allowed:

- "This sample integrates with CoAkka."
- "MyProject is compatible with CoAkka runtime artifacts."
- "This fork is based on the public CoAkka samples, with changes."

Not allowed without written permission:

- naming an unofficial runtime, hosted service, or fork "CoAkka"
- publishing images or packages under names that look like official CoAkka
  artifacts
- using the CoAkka name or logo to imply endorsement, certification, support,
  or project ownership
