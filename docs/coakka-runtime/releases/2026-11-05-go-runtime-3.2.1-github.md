# Go Runtime 3.2.1 on GitHub

Released 2026-11-05: [GitHub Release v3.2.1](https://github.com/phuong-tran/coakka-runtime-go/releases/tag/v3.2.1).

```sh
go get github.com/phuong-tran/coakka-runtime-go/v3@v3.2.1
```

Use the existing `/v3` import path. The first two version numbers identify
bundled Core generation 3.2, and the last identifies Go connector revision 1.
No separate Core install is required. Use Go 1.22.12 or later and a C11 cgo
compiler; native Windows ARM64 uses Go 1.25.5 and a matching ARM64 compiler.

source. Go verified the download against its checksum database. A fresh macOS
ARM64 consumer installed it without module replacements or a native-library
override, sent a request, received `accepted-hello`, and closed the host.
