# Runtime Client and Inspect 3.2.1

Released on 2026-11-05. Client and Inspect 3.2.1 include Core 3.2
build `f9e5a632d2d046a5b4e89d5ce0c9042aee5c7b45` (ABI 1). The
[`coakka-publish` archive commit](https://github.com/phuong-tran/coakka-publish/commit/86aa17f3d2af26bfd0faee3c02fbd9e82750592e)
contains five archives per tool. All ten archives were downloaded anonymously
and checked against their qualified SHA-256 digests and the two public
`SHA256SUMS` files.

Unpack the archive for your platform and keep its bundled runtime files
alongside the executable. Run `coakka-client version` or
`coakka-runtime-inspect version` to see the loaded Core version (3.2);
the archive name records the tool package version (3.2.1).

## Execution evidence

The qualified archive bytes passed installed connected checks on macOS
ARM64, Raspberry Pi 5 Linux ARM64, Linux x64 on WSL2, physical Windows x64,
and Windows ARM64 in UTM. The checks exercise Client request/reply and the
Inspect server's snapshot and route try paths. The macOS archives downloaded
from Publish also ran the `version` command and reported the expected Core
commit and ABI.

The Docker demonstration images retain their separately verified 2.5.1
version. See [the 2.5.1 tool record](2026-08-21-runtime-tools-2.5.1.md) for
their digests and execution evidence.
