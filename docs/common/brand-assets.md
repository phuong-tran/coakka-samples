# CoAkka Brand Assets

CoAkka uses one shared visual identity across the runtime, logger, tools,
connectors, samples, and package-manager surfaces. These assets are canonical;
language packages should link to or copy them instead of redesigning the mark.

The guardian mark combines a crown-like mythic seal, a central `C`, two
message arcs, and two peer nodes. It represents protected coordination around
one runtime contract without depicting a literal deity or religious figure.

## Files

| Asset | Use |
| --- | --- |
| [`coakka-logo.png`](assets/brand/coakka-logo.png) | Universal README and registry image on a fixed ivory background. |
| [`coakka-logo-light.svg`](assets/brand/coakka-logo-light.svg) | Transparent horizontal lockup for light surfaces. |
| [`coakka-logo-dark.svg`](assets/brand/coakka-logo-dark.svg) | Transparent horizontal lockup for dark surfaces. |
| [`coakka-mark.svg`](assets/brand/coakka-mark.svg) | Transparent standalone mark for light surfaces. |
| [`coakka-icon-dark.svg`](assets/brand/coakka-icon-dark.svg) | Square repository, package, application, and social icon. |

PNG equivalents are provided for registries and renderers that do not accept
SVG. The universal PNG is the default for package README files because its
fixed background remains legible in both light and dark themes.

## Usage Rules

- Keep the wordmark spelling and capitalization exactly `CoAkka`.
- Preserve aspect ratio and keep clear space of at least one node diameter.
- Use the horizontal lockup at 160 CSS pixels wide or larger.
- Use the standalone mark or square icon below that size.
- Do not recolor individual parts, distort the geometry, add effects, or place
  the transparent light/dark variants on a surface with insufficient contrast.
- Use alt text `CoAkka` for the horizontal logo and `CoAkka guardian mark` for
  the standalone mark.

Trademark and redistribution rules remain defined by the public repository's
`TRADEMARKS.md` and artifact license. The logo does not change binary or sample
license terms.
