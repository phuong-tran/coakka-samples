# CoAkka HTTP Runtime for Python 2.3.1

Released on 2026-11-17 to PyPI as `coakka-http-runtime-python==2.3.1`.
The connector uses Core generation `2.3`, native SDK `2.3.0` and C ABI 10.
The final `1` identifies the first Python connector revision on this Core
generation. [PyPI package](https://pypi.org/project/coakka-http-runtime-python/2.3.1/)

```sh
python -m pip install coakka-http-runtime-python==2.3.1
```

Use CPython 3.11 or newer on Linux ARM64/x86-64, macOS ARM64 or Windows
ARM64/x64. The wheel includes its matching native SDK and Python bridge.
The package README covers the first request and a complete example that
serves HTTP/1.1, HTTP/2 and HTTP/3 on one TLS port.
[Python guide](https://github.com/phuong-tran/coakka-publish/blob/main/coakka-http-runtime/python/README.md)

## Verified publication

PyPI lists all 5 admitted wheels. Each was downloaded from
`files.pythonhosted.org` and its SHA-256 matched the qualified artifact.
Fresh environments on the physical Mac, Raspberry Pi 5, Windows x64 and
Windows WSL2 installed version 2.3.1 directly from PyPI. Each passed the
public request/response and repeated open/close consumer. Runtime inspection
verified the actual loaded native image against the qualified SDK.
Windows ARM64 has the prior exact-wheel correctness receipt.
