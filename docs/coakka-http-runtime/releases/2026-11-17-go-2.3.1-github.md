# CoAkka HTTP Runtime for Go 2.3.1

Released on 2026-11-17 through GitHub Releases as **v2.3.1**. The module is
`github.com/phuong-tran/coakka-http-runtime-go/v2` and uses Core generation
**2.3**, native SDK **2.3.0** and C ABI **10**. The final `1` is the first Go
connector revision on Core 2.3. Go 1.23 remains the language minimum.

```sh
go get github.com/phuong-tran/coakka-http-runtime-go/v2@v2.3.1
```

Download the native SDK for your target and verify it against `SHA256SUMS`
before extracting it. The Go module supplies source; the SDK supplies the
headers and shared library for cgo. WSL2 uses the Linux x86-64 artifact.

## Verified publication

All 5 native SDK assets and the checksum file were downloaded anonymously
from the public release and matched to the qualified bytes. Fresh module
installations with the normal public Go proxy and checksum database passed
on the physical Mac, Raspberry Pi 5, Windows x64 and Windows WSL2. Each
verified the exact module tree, actual loaded Core image, repeated public
request/response lifecycle and HTTP/1.1, HTTP/2 and HTTP/3 on one TLS port.
Windows ARM64 has the exact final-module correctness receipt before release.
