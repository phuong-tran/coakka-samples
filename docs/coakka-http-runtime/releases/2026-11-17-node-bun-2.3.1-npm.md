# CoAkka HTTP Runtime for Node.js and Bun 2.3.1

Released on 2026-11-17 as `coakka-http-runtime-node@2.3.1` and
`coakka-http-runtime-bun@2.3.1`. Both use Core generation **2.3**, native
SDK **2.3.0** and C ABI **10**. The final `1` identifies the first revision
of each connector on this Core generation.

```sh
npm install coakka-http-runtime-node@2.3.1
bun add coakka-http-runtime-bun@2.3.1
```

Use Node.js 22 or newer, or Bun 1.2.22 or newer. Each package includes its
matching native runtime and adapter for Linux ARM64/x86-64, macOS ARM64
and Windows ARM64/x64. The package README contains the first request and a
complete `multiProtocolListener` example serving HTTP/1.1, HTTP/2 and HTTP/3
on one TLS port. Existing requests retain their handler when `swapHandler`
changes the callback for later requests.

## Verified publication

Both public npm tarballs were downloaded and matched to the qualified
SHA-256 and npm SHA-512 integrity values. Fresh public-registry installs
passed on the physical Mac, Raspberry Pi 5, Windows x64 and Windows WSL2.
Both runtimes passed request/response, same-port three-protocol callback
replacement, close and reopen. The running processes mapped the qualified
Core and adapter images. Every installed package file matched the admitted
archive. Windows ARM64 has the prior exact-archive correctness receipt.
