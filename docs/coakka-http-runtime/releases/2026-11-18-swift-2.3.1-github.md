# CoAkka HTTP Runtime for Swift 2.3.1

Released on 2026-11-18 through
[GitHub Release v2.3.1](https://github.com/phuong-tran/coakka-http-runtime-swift/releases/tag/v2.3.1).
Use Swift 6.0 or a compatible newer toolchain and import `CoAkkaHttp`.

```swift
.package(url: "https://github.com/phuong-tran/coakka-http-runtime-swift.git", exact: "2.3.1")
```

In 2.3.1, **2.3** is the Core generation and **1** is this connector's
first revision on that Core. This release uses native SDK **2.3.0** and
C ABI **10**. SwiftPM resolves the Git tag; all 5 native targets are included.
WSL2 uses the Linux libraries. A separate native SDK download is not required.
Follow the platform-specific launch instructions in the README.

Serve HTTP/1.1, HTTP/2 and HTTP/3 separately or use
`HttpListener.multiProtocolListener` for buffered requests on one TLS port.
Supported standalone listeners provide uploads, response streams/trailers,
SSE, WebSockets, file delivery, monitoring, rebind and TLS/mTLS control.
The outbound client calls HTTP/1.1 upstreams with plaintext, TLS or mTLS.
