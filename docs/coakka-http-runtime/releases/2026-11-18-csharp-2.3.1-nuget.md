# CoAkka HTTP Runtime for C# 2.3.1

Released on 2026-11-18 as **CoAkka.Http.Runtime 2.3.1** on NuGet.
The package targets **net8.0**, with installed checks on .NET 8 and 10.
The assembly is `CoAkka.Http.dll`; applications import `CoAkka.Http`.

```sh
dotnet add package CoAkka.Http.Runtime --version 2.3.1
```

In 2.3.1, **2.3** identifies the Core generation and **1** is the first
C# connector revision on that generation. This package uses native SDK
**2.3.0**, C ABI **10**, and contains native libraries for macOS ARM64,
Linux x64/ARM64 and Windows x64/ARM64. WSL2 uses Linux assets.

Use `HttpListenerOptions.MultiProtocolListener` for buffered HTTP/1.1,
HTTP/2 and HTTP/3 on one TLS port. Use supported standalone listeners for
streaming, trailers, SSE, WebSocket, uploads, file delivery and TLS/mTLS
control. Outbound calls expose cancellation and Core-issued terminal results.
