# CoAkka HTTP Runtime for Java and Kotlin 2.3.1

Released on 2026-11-18 through Maven Central:
**io.github.phuong-tran.coakka:coakka-http-runtime-jvm:2.3.1**.
The library supports Java 8 or newer. The README applications use JDK 17
and Kotlin 2.3.10.

In 2.3.1, **2.3** identifies the Core generation and the final **1** is the
first JVM connector revision on that generation. This release uses native
SDK **2.3.0** and C ABI **10**. Java and Kotlin use the same managed JAR;
choose the native ZIP matching the operating system and architecture of
the JVM running the application. WSL2 uses a Linux classifier.

```xml
<dependency>
    <groupId>io.github.phuong-tran.coakka</groupId>
    <artifactId>coakka-http-runtime-jvm</artifactId>
    <version>2.3.1</version>
</dependency>
```

```kotlin
implementation("io.github.phuong-tran.coakka:coakka-http-runtime-jvm:2.3.1")
```

Use `MultiProtocolListener` for buffered HTTP/1.1, HTTP/2 and HTTP/3
requests on one TLS port. Complete Java and Kotlin examples, Maven and
Gradle native installation, and standalone protocol selection are in the
[JVM guide](https://github.com/phuong-tran/coakka-publish/blob/main/coakka-http-runtime/jvm/README.md).
Use standalone profiles for streaming, SSE, WebSocket, mTLS and live TLS
or route control.
