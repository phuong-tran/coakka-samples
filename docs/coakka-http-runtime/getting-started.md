# Start With CoAkka HTTP Runtime

**Choose your language, start a service and send one request.**

Start with the [2.2.1 examples](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/protocol-listeners/README.md) for C, C++, Go, Node.js,
Bun, Python, Java and Kotlin. Choose HTTP/1.1, HTTP/2 or HTTP/3 and
check the protocol that curl reports. C, C++ and Go use
[Core SDK 2.2.0](https://github.com/phuong-tran/coakka-http-runtime-go/releases/tag/v2.2.1).

## First-request examples for 2.0.1

Run a first request with a public HTTP Runtime 2.0.1 package for Node.js, Bun,
Python, Go or JVM, or use the focused native SDK for C and C++.
[Registry samples](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/registry-basic/README.md) · [Native SDK](https://github.com/phuong-tran/coakka-publish/tree/main/coakka-http-runtime/native/releases/2.0.1)

## Choose your language

| Your application | Run your first request with 2.0.1 |
| --- | --- |
| Node.js or Bun / TypeScript | [Install the package and run the JavaScript sample](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/registry-basic/README.md#nodejs-and-bun) |
| Python | [Create a virtual environment and run the Python sample](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/registry-basic/README.md#python) |
| Kotlin or Java | [Get the JVM package and run a first request](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/registry-basic/README.md#jvm) |
| Go | [Install the Go module and matching native SDK](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/registry-basic/README.md#go) |
| C or C++ | [Build the native server example](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/native/host-server/README.md) |

Expect `HTTP 200 hello` from the registry examples. The native examples
include their own build commands and expected output.
