# CoAkka HTTP Runtime Documentation

Build an HTTP service with handlers written in your application's language.
HTTP Runtime owns the shared HTTP service contract; application logic stays
in the application. This product has its own packages and version.

## Start

[Run one service and send one request](getting-started.md), or
[download the matching package](https://github.com/phuong-tran/coakka-publish/blob/main/coakka-http-runtime/README.md).
The current 1.0.0 distribution uses repository archives, not package registries.

## Use and operate

- [Task guides](guides/README.md): files, uploads and other application features.
- [Operations](operations/README.md): observe, secure and run a service.
- [Reference](reference/README.md): capabilities, vocabulary and exact contracts.
- [Explanations](explanation/README.md): product choices and the application model.

[Inspect metadata and OpenAPI](https://github.com/phuong-tran/coakka-publish/blob/main/docs/coakka-http-runtime/inspect/metadata-and-openapi.md)
is an optional companion. [Recorded benchmarks](https://github.com/phuong-tran/coakka-publish/blob/main/docs/coakka-http-runtime/benchmarks/benchmark-results-rpi5.md)
describe their workload and hardware; they do not predict every application.
