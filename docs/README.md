# CoAkka Documentation

**Choose a product, then start in the language you know.**

CoAkka is a polyglot, cross-platform ecosystem built on shared native cores.
Your application keeps its handlers and business rules. Each product can be
used independently and has its own packages and version.

| I want to… | Product | First step |
| --- | --- | --- |
| Call application work across processes or languages | CoAkka Runtime | [Choose my language and run an example](coakka-runtime/getting-started.md) |
| Build an HTTP API, web service or streaming endpoint | CoAkka HTTP Runtime | [Choose my HTTP language guide](coakka-http-runtime/getting-started.md) |
| Record logs and see when output cannot keep up | CoAkka Logger | [Choose my Logger example](coakka-logger/README.md#start-with-one-consumer) |

## New here?

[New to CoAkka](common/new-to-coakka.md) explains the products with one ordinary
application example. For Runtime, follow this path:

1. [Run one request and see its reply](coakka-runtime/getting-started.md).
2. [Choose an example for your use case](coakka-runtime/guides/examples-and-use-cases.md).
3. [Put the same steps in your application](coakka-runtime/guides/runtime-integration-guide.md).

You only need your chosen language's tools for the first step. Start locally;
deployment and advanced settings can come later.
