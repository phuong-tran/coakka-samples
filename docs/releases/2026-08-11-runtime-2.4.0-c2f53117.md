# Runtime 2.4.0 Artifact Release

The repository artifact release promotes native generation
`2.4.0+c2f53117` and connector generation
`2.4.0+c2f53117-0afb5e9`.

## Runtime Behavior

- `EMBEDDED` is the default and does not open a TCP listener.
- `OUTBOUND_ONLY` permits remote routes without opening a listener.
- `NETWORK_NODE` requires explicit bind and advertise endpoints and fails
  startup when its bind cannot be established.
- Local endpoint port `0` means the runtime is intentionally not listening;
  route configuration does not implicitly enable a listener.

## Artifacts

The native archive contains Linux ARM64/x86-64, macOS ARM64, and Windows
ARM64/x86-64 libraries with 133 public exports. The JVM, Spring Boot, Quarkus,
Node.js, Bun, Electron, Python, Go, C#, Rust, Swift, Mojo, Zig, and Tauri
repository artifacts use the same native generation.

Linux builds execute their runtime identity probe on matching architecture.
The macOS connector and packaged-consumer matrix passes on ARM64. Windows
binaries pass cross-build, PE architecture, export, dependency, digest, and
package gates; matching-host Windows execution is not yet recorded for this
generation.

## Publication Boundary

This receipt covers immutable files in `coakka-publish`. npm, PyPI, NuGet, Go
module, and SwiftPM publication is a separate step. Their current verified
registry coordinates remain the 2.3.0 train until individual registry receipts
say otherwise.
