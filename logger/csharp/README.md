# C# Logger Samples

C# logger samples consume published `CoAkka.Logger==1.2.3` from NuGet. They
target `net8.0`; the same package is verified on .NET 8, 9, and 10 and embeds
native logger generation `1.2.1+f50756ebff0d`.

Run both C# logger samples:

```sh
bash run.sh logger csharp basic
bash run.sh logger csharp pressure
```
